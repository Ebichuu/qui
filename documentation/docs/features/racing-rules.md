---
title: 候选与规则选择（开发中）
---

RSS 和网页发现同站同一首发或复活事件后，合并为一个候选。标题或 hash 相同的不同站点仍保留独立记录。补充来源和重启不会重置首次发现时间。

官种、免费和复活分别保留真、假、未知。规则多选接收类型时，命中任一类型即可；关键词、大小与接收窗口等条件仍需同时满足。实际官种优先选择接收官种的命中规则，同类按配置顺序选择一条完整规则。目标不可用时等待该目标；窗口到期时退出，不从其他规则借用目标、权限或更长窗口。

缺少必要证据时等待，不把未知官种归入普通组。网页显示的近似大小不能直接用于精确大小边界；必要时后台单独获取该候选的种子元数据，核实大小与真实 hash。种子文件不能证明官种或免费，无法可靠补齐的字段仍保持未知。

## 查询结果

经过认证后，`GET /api/racing/candidates` 返回候选、合并证据、选中规则、缺失字段和接收截止时间。每次最多返回 100 项，下一页使用返回的 `nextCursor` 作为 `after` 参数。

| 状态 | 含义 |
|---|---|
| `rejected` | 没有匹配规则，或来源已移除 |
| `waiting_metadata` | 必要证据缺失或冲突 |
| `waiting_target` | 选中规则的配置目标不可用 |
| `expired` | 选中规则的接收窗口已关闭 |
| `ready` | 只读规则匹配通过 |

`ready` 只表示规则匹配通过，不表示已添加。下载器明确启用接种后，后台才会继续选机、预留和添加，阶段结果见[接种记录](racing-reception.md)。尚未提交的动作按最新配置重新评估；已提交的请求保留原目标和规则。接口不公开凭据、下载地址或原始种子文件。

## 配置与匹配预览

在 RSS → qui 统一来源 → 规则中选择来源、接收类型和一个下载器或群组。接收窗口须明确填写；关键词、大小和“允许官种腾空间”位于展开选项中。回收条件及预算属于下载器，当前阶段只记录允许开关。

上移、下移一次保存完整规则顺序，只改变排序字段。规则列表变化或 ID 重复时整次拒绝，不产生部分排序，也不覆盖其他窗口编辑的目标或权限。

“匹配预览”显示后台按已保存规则产生的结果、选中规则、缺失证据及首次发现时间，每五秒刷新，可分页查看。来源请求失败与恢复可在现有日志中按 `racing` 查看；开启 Debug 日志后可查看逐次采集耗时、条目数与候选评估状态。日志使用稳定 ID 和固定错误分类，不包含来源 URL、Cookie 或种子标题。
