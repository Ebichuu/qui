# 竞速配置（Q1）

`racing/develop` 的 Q1 阶段保存独立于 qB RSS 的配置。后台随 qui 进程启动和停止，重启后从数据库恢复；关闭页面或断开 SSE 不会停止它。当前不抓取来源，不自动添加、删除或重新汇报种子，也不接管已有 qB RSS 规则。

## 配置对象

- **站点**：名称、站点根地址、启用状态、Tracker 主机名、请求最小间隔及服务端凭据引用。
- **来源**：关联一个站点，记录 RSS、网页或复活来源类型、启用状态、独立周期及加密地址。
- **群组**：名称、启用状态及现有下载器成员。重复成员自动去重，允许同一下载器属于多个群组。空群组可以保存；它没有可执行目标。群组不代表磁盘，也不授予自动操作权限。
- **RSS 规则**：引用一个或多个来源，保存接收类型、筛选条件、顺序、接收窗口和一个明确目标。目标必须为一个现有下载器或一个群组，不能同时选择二者。

官种、免费和复活接收项按“或”组合，其他筛选条件按“且”组合。接收窗口必须显式配置，没有统一的三分钟默认值。规则上的官种回收开关只保存意图；它不能授权删除或提前开启 Q3 能力。

来源抓取、候选的独立三态证据和实际规则求值在后续批次接入；不能把配置已启用当作已经运行抢种。

## API 和凭据

现阶段配置接口位于 `/api/racing`，沿用原有登录/API key 认证：

- `GET /configuration` 返回全部配置；`GET /status` 返回后台状态，模式固定为 `observe_only`。
- `POST /sites`、`/sources`、`/groups`、`/rules` 创建对象，返回稳定 ID。
- `PUT /{类型}/{id}` 替换配置；改名或停用保留 ID 和其他对象的引用。
- `DELETE /{类型}/{id}` 删除对象。仍被引用的站点、来源和群组返回 409，需先解除引用。

站点根地址只能包含 HTTP(S) 协议和主机，不接受凭据、查询参数或私有路径。完整来源地址和站点凭据加密存储在服务端，响应只包含来源的协议/主机及 `hasCredential`。修改来源时省略 `url` 保留原地址；修改站点时省略 `credential` 保留原凭据，明确传空字符串才清除。不要把 passkey 或 Cookie 写入名称、Tracker 主机名或其他普通字段。

群组成员及直接规则目标引用现有实例；被引用实例不能直接删除。新增配置不修改实例密码、原有自动化、qB RSS 或执行权。

具体输入字段、取值范围和响应见随程序提供的 OpenAPI。现有 RSS 页面继续管理未交接的 qB 订阅；qui 来源的页面配置将在 C07 接入同一 RSS 入口。
